# TaskQuest – Android Task Management Application

## About the Project

TaskQuest is an Android application designed to help users organise their daily activities, manage tasks and improve productivity.

The application aims to make task management easier by providing users with a convenient platform to keep track of their activities and responsibilities.

## Project Objectives

- Help users organise their daily tasks.
- Improve time management and productivity.
- Make task tracking easier.
- Provide a user-friendly mobile application.

## Features

- User-friendly interface.
- Task management.
- Task organisation and tracking.
- Easy navigation.
- Android mobile support.

## Installation and Setup

1. Download or clone this repository.
2. Open Android Studio.
3. Select **Open**.
4. Choose the TaskQuest project folder.
5. Allow Gradle to synchronise.
6. Connect an Android phone using a USB cable.
7. Enable Developer Options and USB Debugging on the phone.
8. Select your connected device in Android Studio.
9. Click the **Run** button to install and launch the application.

## Requirements

- Android Studio.
- Android SDK compatible with the project configuration.
- Kotlin support.
- Gradle.
- An Android smartphone or emulator.
